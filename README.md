### 🕹️ 操持法門（使用方法）

1. **析匱解囊**：先解壓發行壓縮包（`.7z`）。
2. **啟門發軔**：雙擊運行啟動器程序。
3. **循途認徑**：按引導選定本機各遊戲所在之目錄。
4. **學園奧秘**：若欲整備學園主數據與各路資源，請詳讀包內「**發行先覽**（解壓後先讀）」之文，循序而進即可。

### 📜 庫藏底蘊（倉庫現狀）

本庫備齊各版啟動器之介面全副源流，兼載學園本地伺服、更新腳本與代理法門。  
若欲運行本地伺服，須於本機預設兩道關鍵之數（環境變量）：
* `GKM_AESKEY`
* `GKM_SECKEY`
* *(二者皆取十六進制之值)*  

諸般部件與發行成品皆已點核停當，請諸君隨心取用。
