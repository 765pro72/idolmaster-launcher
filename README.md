### 🕹️ 操持法门（使用方法）

1. **析匮解囊**：先解压发行压缩包（`.7z`）。
2. **启门发轫**：双击运行启动器程序。
3. **循途认径**：按引导选定本机各游戏所在之目录。
4. **学园奥秘**：若欲整备学园主数据与各路资源，请详读包内「**发行先览**（解压后先读）」之文，循序而进即可。

---

### 📜 库藏底蕴（仓库现状）

本库备齐各版启动器之界面全副源流，兼载学园本地伺服、更新脚本与代理法门。  
若欲运行本地伺服，须于本机预设两道关键之数（环境变量）：
* `GKM_AESKEY`
* `GKM_SECKEY`
* *(二者皆取十六进制之值)*  

诸般部件与发行成品皆已点核停当，请诸君随心取用。
