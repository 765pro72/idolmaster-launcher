# 偶像大师启动器

这是一个面向 Windows 的偶像大师系列启动器，用于集中启动游戏、管理本地服务和同步学园偶像大师的本地内容。

## 版本

- **两游戏版**：学园偶像大师、偶像大师 百万现场！剧场时光。
- **四游戏版**：在两游戏版基础上加入偶像大师 灰姑娘女孩 星光舞台和偶像大师 闪耀色彩。

## 使用方法

解压发行包，打开启动器，按提示选择对应的游戏目录。学园的主数据和游戏资源准备方法见发行包内的「解压后先读」。

## 仓库状态

仓库包含两游戏版与四游戏版的启动器界面源码，以及学园本地服务、更新脚本和代理源码。运行本地服务需要在本机配置环境变量 `GKM_AESKEY` 和 `GKM_SECKEY`，值为十六进制。其他组件和发行压缩包仍待核对。
