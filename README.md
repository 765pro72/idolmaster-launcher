### 贰 · 析匮操范

1. **解匮发轫**：获奉金函，析而剖之。
2. **叩键行枢**：双叩总辖之纽，百司齐启。
3. **辨方正位**：循引而授各门艺苑之册府径路。
4. **探求密要**：整备学园图谱，先察函内「发轫前省」之告戒。

---

### 叁 · 秘府底蕴

此案备载二曜与四维全副原本，兼藏学塾私舍、考校演历与通幽诸法。  
欲立私舍之域，须在几案定置阴阳二道铁契符节（二气合和，莫失分寸），始得驱策。
